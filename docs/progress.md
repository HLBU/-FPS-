## 阶段 1：最小项目与启动说明（2026-10-30）

### 范围与实现

- 开工前检查：目录只有 `.git` 和 `.gitattributes`，工作区干净；没有覆盖已有文件，没有导入旧项目代码。
- 使用 TypeScript、Vite、Three.js 建立本地浏览器项目；依赖由 npm 安装并锁定。
- 启动页包含静态 3D 网格与立方体，验证 WebGL 初始化、尺寸适配与资源释放；不包含游戏玩法。
- 提供图形初始化失败提示、运行说明和可重复的浏览器启动检查。
- 本阶段没有新增游戏素材；保留第三方依赖许可证。

### 验证

- 环境：Windows、Node.js 24.14.0、npm 11.9.0、本机 Chrome。
- `npm.cmd install` 成功，审计 27 个包，0 个已知漏洞；提交锁文件，供其他电脑使用 `npm.cmd ci` 安装。
- `npm.cmd run build` 通过，包含 TypeScript 严格检查和 Vite 生产构建。
- 开发服务 `http://127.0.0.1:5173/` 与生产预览 `http://127.0.0.1:4173/` 的真实浏览器检查均通过：HTTP 成功、WebGL 渲染就绪、无控制台/页面/网络请求错误。
- 检查并目视确认 1280×900 和 390×844 截图，立方体与网格可见、文本完整、窄窗口无横向溢出。截图位于忽略提交的 `artifacts/`。
- 首次开发页浏览器检查等待渲染就绪超过 30 秒；改进检查脚本的错误状态报告后，重跑开发页及生产预览均通过，未复现。原因尚未确定，不能据此声称所有电脑首次启动都已验证。
- `git diff --check` 通过，原 `.gitattributes` 未改动。
- 未验证：另一台电脑重新安装、手动前台交互体验、其他浏览器与硬件。当前没有玩法，不能将这些检查视作游戏验收。

### 下一阶段：地图、鼠标与基本移动

1. 按地图尺寸建立竞技场与出生点，以米为单位；内部掩体与外围边界区分。
2. 实现 Pointer Lock 鼠标转向、拒绝/退出后的恢复入口。
3. 实现 5.2 米/秒步行、7.28 米/秒疾跑，斜向归一化，松键停止主动移动。
4. 实现重力 15、跳跃初速 6.2，以及地面、墙体和平台碰撞。
5. 验证站定/移动/腾空转向、碰墙、跳跃及窗口调整。第二阶段仍不包含射击和联机。

### 后续风险与约束

- 模型、姿态、视点、枪口与受击区必须保持一致。
- 先验证移动及反推手感，再完成人机闭环，最后接真人联机。
- “五局三胜”按先赢三局处理；平局重赛，实际小局数可能超过五局。
- 外围墙高 6 米、脚底高度上限 8 米：后续碰撞需要额外约束水平场地边界，保证不能越界。
- 真人阶段需要服务端权威判定和独立选卡隐私，不能直接把单机客户端状态作为可信结果。

## 阶段 2：竞技场、鼠标与基本移动（2026-10-30）

### 实现

- 读取第一阶段代码及地图规格，保留现有工程与依赖；无新增第三方依赖或外部素材。
- 按 36×30 米场地、15 个规格障碍物和双侧出生位置生成场景；渲染和碰撞共用地图数据。
- 玩家从 (-9,0,12) 朝向对侧出生点进入，站立高度 2 米、视点高 1.74 米、碰撞半径 0.33 米。
- 原生 Pointer Lock 鼠标转向，俯仰限位；被拒绝时显示恢复提示，另有明确标注边缘限制的窗口模式。
- WASD、左右 Shift、空格；步行 5.2、疾跑 7.28 米/秒，斜向归一化，松键停止主动水平移动。
- 重力 15、跳跃初速 6.2，可落地连跳；圆柱水平碰撞、贴墙滑动、平台支撑、顶棚阻挡，最多 1/120 秒子步避免穿透。
- 场地水平边界独立于可见墙体高度，防止以后获得反推后翻出地图。
- ESC/失焦/切后台暂停模拟并清键，点击恢复，菜单可重置出生点；HUD 展示实际速度、高度、状态与坐标。

### 已验证

- `npm.cmd run test:physics`：8 项通过，涵盖 30/60/144 FPS 的速度与斜向距离、朝向移动、地面/空中松键停止、跳跃最高点/连跳、低 FPS 防穿墙、贴墙滑动、平台上下、顶棚与高空边界。
- 数值检查发现并修复贴墙切向移动的浮点误差，防止角色横向突跳；修复后检查全部通过。
- `npm.cmd run build`：严格类型检查与生产构建通过。
- 开发服务 Chrome 交互检查通过；更新后的完整检查在生产预览 http://127.0.0.1:4173/ 通过。
- 真实浏览器检查覆盖 WebGL、原生鼠标锁定、地面与空中转向、移动/松键停止、跳跃、暂停冻结/恢复锁定、出生重置、右 Shift、窗口模式；通过模拟 blur 检查清键，通过模拟浏览器策略拒绝检查错误提示和恢复。
- 无浏览器控制台/页面/请求错误；已查看 1280×900 的菜单与场景、390×844 的菜单截图，未发现溢出或文本遮挡。
- `git diff --check` 通过。
